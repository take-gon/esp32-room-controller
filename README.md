# ESP32 Room Controller

ESP32を使用して、室内の温湿度表示やエアコン制御を行うための個人開発プロジェクトです。

## 概要

OLEDディスプレイに温湿度を表示し、
将来的には赤外線通信を使用してエアコンを操作できるようにする予定です。

## 使用機器

- ESP32-DevKitC-32E
- 0.96インチ OLEDディスプレイ
- SHT31 温湿度センサー
- 赤外線LED
- タクトスイッチ
- 2SC1815
- 1kΩ抵抗
